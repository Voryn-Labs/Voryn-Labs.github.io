Excly

Windows Excel shortcuts, natively restored in Excel for Mac.

Excly is a native macOS companion engineered to bring familiar Windows ribbon shortcuts (like Alt H O I to AutoFit columns) to Microsoft Excel for Mac. Handcrafted in pure Swift with AppKit, SwiftUI, Core Graphics event taps, and macOS Accessibility APIs.

Why macOS Shows a Security Prompt

Because Voryn Labs software is 100% free and open-source, we do not pay an annual Apple Developer certificate tax. When launching downloaded apps for the first time, macOS Gatekeeper may show: "Excly cannot be opened because Apple cannot check it for malicious software". Excly is completely open source with public source code, zero background servers, and zero telemetry. Follow either method below to authorize launch.

Method 1: Control-Click (GUI)

Recommended

Authorize Excly directly through Finder without touching the command line.

  1. 1 Open the downloaded Excly-1.0.0-macOS.dmg and drag Excly.app into your /Applications folder.
  2. 2 In Finder, open /Applications, hold Control (or right-click) on Excly.app, and choose Open from the menu.
  3. 3 In the security dialog asking "Are you sure you want to open it?", click Open. This permanently saves an exception for Excly.

Tip: You can also go to System Settings → Privacy & Security, scroll down to Security, and click "Open Anyway".

Method 2: Strip Quarantine Flag

Instant CLI

For power users: strip macOS download quarantine flag in one terminal command.

  1. 1 Move Excly.app to your /Applications folder.
  2. 2 Open Terminal.app (hit ⌘ Space and type Terminal).
  3. 3 Run the following command to remove the quarantine attribute:
xattr -cr /Applications/Excly.app

Required Step: Grant Accessibility Permission

Required

Because Excly listens for Alt/Option ribbon sequences while Microsoft Excel is the active application, macOS requires explicit Accessibility authorization. When prompted, or at any time in system preferences:

System Settings → Privacy & Security → Accessibility → Toggle Excly ON

Build from Source

Prefer to inspect and compile the code yourself? Excly is 100% open source under Voryn Labs. Compile universal binaries in seconds with Swift Command Line Tools.

Terminal — Build Excly from Source 
# 1. Clone the official repository
git clone https://github.com/Voryn-Labs/Excly.git
cd Excly

# 2. Compile standalone universal binary (Apple Silicon + Intel)
./scripts/build-app.sh

# 3. Launch the compiled application
open dist/Excly.app
