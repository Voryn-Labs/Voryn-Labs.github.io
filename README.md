# Voryn Labs — Games Hub

Public GitHub Pages site for the Voryn Labs 14-game portfolio.

Live: https://tinyredphoenix.github.io/vorynlabs-games/

- **Landing + app showcase**: `docs/index.html`
- **Privacy policy**: `docs/privacy.html`
- **Single update point**: `docs/assets/js/apps.js` — set a game's `storeUrl` to flip its badge to "Get it on Google Play"
- **Icon refresh**: `python3 tools/extract_site_icons.py`
- **Registry validation**: `python3 tools/validate_site.py`

> This repo intentionally contains ONLY the static site. The application source lives in a separate private repository.
